# Iris Flower Classification Using Machine Learning

## Project Overview
This project focuses on classifying Iris flowers into three species using Machine Learning algorithms in Python.

The classification is based on four features:
- Sepal Length
- Sepal Width
- Petal Length
- Petal Width

## Technologies Used
- Python
- Google Colab
- Pandas
- NumPy
- Matplotlib
- Scikit-learn
- Joblib

## Machine Learning Algorithms
1. Logistic Regression
2. Decision Tree Classifier

## Project Workflow
1. Dataset Loading
2. Data Preprocessing
3. Feature Scaling
4. Model Training
5. Decision Boundary Visualization
6. Classification Report
7. Confusion Matrix
8. Model Accuracy Comparison
9. New Flower Prediction
10. Model Saving and Loading

## Model Performance

| Algorithm | Accuracy |
|---|---:|
| Logistic Regression | 96.67% |
| Decision Tree | 93.33% |

## Conclusion
Both machine learning algorithms were successfully implemented and evaluated. Logistic Regression achieved 96.67% accuracy, while Decision Tree achieved 93.33% accuracy on the test dataset.

Therefore, Logistic Regression performed better on this test dataset.
